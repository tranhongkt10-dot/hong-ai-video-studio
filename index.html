Bản dựng hiện tại xuất video hình ảnh WebM qua MediaRecorder. Âm thanh đọc thử bằng speechSynthesis không được tự động ghi vào video. Muốn có nhạc/lời đọc trong video, có thể thêm file âm thanh vào bản nâng cấp tiếp theo hoặc ghép bằng phần mềm dựng video.

06 · Lưu dự án

Dự án lưu trên thiết bị hiện tại dưới dạng JSON; không đồng bộ đám mây.

Giới hạn & định dạng

  • WebM: xuất trực tiếp khi trình duyệt hỗ trợ MediaRecorder.
  • MP4: cần chuyển đổi bằng FFmpeg/HandBrake hoặc tích hợp bộ mã hóa phù hợp.
  • Không tải tệp lên server; ảnh được xử lý cục bộ.
  • Video dài/độ phân giải cao cần RAM và CPU tốt.
  • Đóng tab khi dựng có thể làm mất tiến trình chưa hoàn tất.

07 · Nền tảng AI bên ngoài

Mở công cụ để gửi prompt và ảnh bằng thao tác thủ công.

Không có API video AI miễn phí, không giới hạn được bảo đảm. Các nền tảng có thể thay đổi hạn mức, yêu cầu tài khoản hoặc tính phí. Không đưa API Key vào GitHub Pages công khai.

08 · Cloudflare Workers (tùy chọn)

Bộ khung Worker đi kèm dùng để kiểm tra kết nối và làm điểm mở rộng backend. Chưa tích hợp nhà cung cấp AI trả phí nên không giả vờ tạo video AI trên server.

09 · Triển khai GitHub Pages

  1. Tạo repository mới tên hong-ai-video-studio.
  2. Đưa index.html lên thư mục gốc (root).
  3. Mở Settings → Pages.
  4. Chọn Deploy from a branch → main → /(root) → Save.
  5. Mở URL GitHub Pages được cấp.

10 · Triển khai Cloudflare Worker

  1. Đăng nhập Cloudflare → Workers & Pages → Create → Worker.
  2. Đặt tên, tạo Worker và mở Edit code.
  3. Dán nội dung file worker.js đi kèm, Deploy.
  4. Sao chép URL dạng https://ten-worker.ten-tai-khoan.workers.dev.
  5. Dán URL vào ô phía trên để kiểm tra.

Worker mẫu có CORS giới hạn theo origin được cấu hình và endpoint health. Trước khi đưa vào sử dụng thật, thay placeholder bằng API backend cụ thể và cấu hình secret qua Cloudflare, không ghi khóa trong mã nguồn.
